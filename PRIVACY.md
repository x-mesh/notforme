# Privacy

NotForMe changes the display of articles in your browser.

## Data that the extension sends

The extension sends an article title and the first 200 characters of its summary to the API endpoint that you configure.

The extension does not send the article body.

The extension sends topic lists when you enable a topic filter.

Publisher labels such as [광고] and [PR] use local rules and do not need an API call.

## Data that the extension stores

Chrome local storage holds the API key, endpoint, model, and classification cache.

Chrome sync storage holds filter settings and display settings.

The API key does not use Chrome sync storage.

The local storage area is not an encrypted secret vault.

## Data that NotForMe collects

NotForMe does not include analytics, advertising, or a NotForMe account.

NotForMe does not send telemetry to the project authors.

The configured API provider can retain or process data under its own policies.

Review the provider terms before you use an endpoint.

## User controls

You can change or remove the API key in the extension popup.

You can clear the classification cache in the extension popup.

You can remove filter settings through Chrome extension storage controls.

The extension requests access to configured HTTPS API hosts and optional HTTPS news sites.
